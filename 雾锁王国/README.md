## 使用

1. 打开 EXE，Steam 安装目录会自动查找；需要时在顶部“选择目录”，选择包含 `enshrouded.exe` 的目录。
2. 所有修改默认关闭。按功能页选择开关；有倍率的项目先输入数值，再开启，关闭确认后才能改数值。
3. 添加物品：在“物品与制作”打开物品工具，显式连接游戏，搜索名称或 ID、选择数量后添加。
4. 地图传送：首次使用或升级地图组件时先正常退出游戏，在“地图传送”按提示准备组件，再自行启动游戏。旧安装有恢复记录时，先“恢复安装前文件”，再安装新版。读取位置与原生路径点后，可保存完整位置并返回，或移动至路径点上空；默认即时移动，也可选择原生施法。
5. 保存点、设置与恢复记录独立保存在 `%LOCALAPPDATA%\CheatL\Enshrouded\data`，可从“说明与状态”打开。更换 EXE 的目录或名称不影响这些记录。旁边保留旧 `雾锁王国工具-20261028` 文件夹时，首次启动会复制已有记录，保留原文件。
