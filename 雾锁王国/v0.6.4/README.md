## 本版优化

- 移除随包 .NET 10 完整运行库，主窗口和角色组件适配系统 CLR，保留私有 JSON 等兼容库和内嵌 Python。
- 按原界面选择规则保留 3898 个物品图标，去除被覆盖或未使用的图；内容去重及无损 WebP 编码，逐图解码核对尺寸、RGBA 像素和 ICC。16 项原本无图的物品仍用原占位图。
- 载荷采用 Windows 原生 LZMS 压缩；逐文件和整包 SHA-256、损坏修复及用户数据隔离保留。
- 沿用原桌面版 11 个组件和 8 个页签，10 个游戏原生 DLL 完全相同；物品数据库、文本、前端界面素材相同，没有删减修改功能。

## 使用

1. 双击 EXE；Steam 目录自动查找，必要时在顶部选择包含 `enshrouded.exe` 的目录。
2. 修改默认关闭，按页签操作。自定义倍率先填数值再开启，关闭后才能编辑。
3. 物品页打开物品工具，显式连接游戏后搜索、选择数量、添加。
4. 地图组件安装或恢复前先正常退出游戏。进入世界后读取位置与原生路径点，可保存/返回位置或传送至路径点上空，默认即时移动。
5. 保存点、设置和恢复账本保存在 `%LOCALAPPDATA%\CheatL\Enshrouded\data`。升级、改名或移动外部 EXE 不影响这些记录。旧桌面文件与旧版本不删除。
