只需下载一个EXE。`version.json`、校验文件和声明供查询，无需放在EXE旁。所需托管依赖、自动挡组件及微软VC++运行库安装器均已内置；使用系统自带的.NET Framework 4.8，支持已具备该环境的Windows 10/11。

### 使用

1. 下载EXE并打开。工具自动检测游戏和当前角色，所有功能默认关闭，也可点击“检测 / 重连”。
2. 首次使用三项自动挡时，正常退出游戏，在“组件准备”页选择游戏的PBZ.exe，点击“一键检查 / 准备组件及运行库”，按系统权限提示完成；无需自行找组件或下载运行库。已经安装且核验一致的组件会复用。
3. 正常进入可控制角色的场景，按需打开开关或填写数值。自动挡以外的功能使用轻量外部/原生后端。
4. 数值开关：输入目标值后开启；已开启时回车或离开输入框提交数值。一次性编辑、添加和保存位置仍用对应按钮。
5. 功能快捷键显示在各项旁，按页面从上到下顺排；无小键盘可切换“主键盘”。**Ctrl+F8**停止三项自动挡。
6. 最后一个“日志 / 诊断”页可导出运行诊断。

### 当前功能

- **生存**：无限生命、无限体力、无限精纯煞炁、无敌、无限暗源、隐身、剩余天数编辑与六十六天难度解锁。
- **战斗**：100%防蓝光、100%抗红光、100%入白刃、硬邦邦、切换武器快速冷却、一击破防和一击必杀。
- **道具**：中文名称目录与搜索、单项/批量添加、移除、数量设定、编辑意识尘埃、编辑当前选中道具数量、药瓶/物品/商店物品不减及无视升级材料需求。
- **探索**：随地传送、五个位置书签及撤销、游戏速度、移动速度、跳跃高度、重力和飞行。

### 随地传送

先按M打开游戏原地图，开启“随地传送”，等待“地图已就绪（100%）”。首次准备显示阶段和实际扫描百分比。

点击非铃铛标记后核对弹窗并确认传送；支持已核验目标的本地图与跨区域传送，跨区域会加载目标地图。铃铛沿用游戏原穿行流程，开启时提供穿行符使用保护。普通标记落点加入角色胶囊高度余量。

跨区期间暂停修改并保留本次会话已开启的持续功能与数值；新场景核验后自动重连并逐项恢复。原地旅行／部分剧情后的暂停也会核对控制状态再恢复。关闭相应开关或Ctrl+F8可取消恢复；不重放道具编辑、添加或上一次传送。新游戏进程默认关闭。位置书签只用于同地图，不等同于跨区标记传送。

### 验证范围与已知限制

游戏速度、移动速度、跳跃高度、重力、Q补充以及部分本图／跨区标记落点已有实机反馈。v0.6.6完整离线检查通过，用户初步使用暂未反馈异常；不同剧情后的恢复仍需更多自然使用反馈，并非所有地图、敌人和道具都已逐项验证。

“100%”为展示名称，不保证所有攻击均可应对。**100%入白刃在战斗状态下会持续防御，难以移动，请谨慎开启。** 硬邦邦不等于免伤或免抓；QTE由玩家手动处理。剧情、特殊伤害及任务/唯一物品有额外规则。

此前部分传送出现过AMD驱动超时，稳定性仍在排查，尚未确认完全消除。遇到异常可停止相关功能并从日志页导出诊断。
