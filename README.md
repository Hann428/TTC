只需下载一个EXE。`version.json`、校验文件和声明供查询，无需放在EXE旁。托管依赖、三项自动挡组件、高亮素材及微软VC++运行库安装器均已内置；使用系统自带的.NET Framework 4.8，支持已具备该环境的Windows 10/11。

### 使用

1. 要用三项自动挡或描边透视，请先保存进度并正常退出游戏，再打开工具的「组件准备」页。自动挡用「一键检查 / 准备组件及运行库」，描边透视用「检查 / 准备高亮素材」。已有组件核验一致时可复用。
2. 准备完成后正常启动游戏，点工具顶部的「检测 / 重连」。进游戏后没有连接，或转场后仍未恢复时，也可点它重新核验。
3. 所有修改默认关闭。按需开启，快捷键以卡片显示为准。Steam 会自动查找安装，手动选择时用实际游戏主程序 `...\Steam\steamapps\common\PBZ\platform\steam\PBZ.exe`。非 Steam 安装在「组件准备」页选择自己的游戏主程序。
4. 数值开关启用后，可回车或离开输入框提交新数值。一次性编辑、添加和位置保存使用对应按钮。没有小键盘可选择「主键盘」。遇到异常可在最后的「日志 / 诊断」页导出诊断。

### 当前功能

- **生存**：无限生命、无限体力、无限精纯煞炁、特效药、无敌、无限暗源、隐身、剩余天数编辑及六十六天难度解锁。
- **战斗**：100%防蓝光、100%抗红光、100%入白刃、硬邦邦、切换武器快速冷却、一击破防、一击必杀。
- **道具**：中文名称搜索、单项与批量添加、移除及数量设定、意识尘埃与选中道具数量编辑、药瓶/物品/商店物品不减、无视装备升级材料需求。任务和剧情物品不提供添加；文书及收藏按游戏规则首次领取一次。
- **探索**：随地传送、描边透视、跳过 CG、五个位置书签及撤销、游戏速度、移动速度、跳跃高度、重力与飞行。

### 描边透视

对已加载场景中的可拾取、可互动目标显示真实轮廓，支持隔墙。绿色表示未领取/未拾取，亮天蓝表示可重复互动，灰色表示已领取/已拾取。地面拾取物显示绿色圆圈，实际拾取后消失。

默认范围420米，可调1～1000米；实际覆盖受游戏场景流送影响。首次使用先准备内置高亮素材。跨区域重新核验后按本次选择恢复；场景成员表暂时流送变化时保留提示等待复核。

### 随地传送与持续功能恢复

按M打开游戏原地图，开启“随地传送”，等待“地图已就绪（100%）”。点击标记后核对弹窗再确认；支持已核验目标的本图/跨区传送，跨区加载目标地图。铃铛沿用原生穿行流程，提供穿行符使用保护；普通标记落点加入角色高度余量。

转场时暂停修改并保留本次会话已开启的持续功能和数值，新场景核验后自动重连并逐项恢复。关闭开关或Ctrl+F8可撤销相应恢复。道具添加、数量编辑和上一次传送等一次性操作不重放；新游戏进程默认关闭。位置书签只用于同地图。

### 本次更新

- **跳过 CG**。在主菜单或过场开始前开启探索页开关。下一段支持的过场中直接长按 **Esc** 约 3 秒，等跳过圆环填满。手柄仍用 B／○，QTE 按游戏提示手动完成。
- **功能排序和快捷键**。各页自研功能在前，参考 FLiNG 加入的功能在后，39 个快捷键按界面顺序重排。跳过 CG 开关为 Ctrl+Num4，主键盘布局对应 Ctrl+4。Ctrl+F8 继续用于停止自动挡。
- **连接和稳定性**。按功能核验游戏布局。优化描边和地图传送的扫描准备，关闭特效药后撤销后续续时和恢复请求。

### 兼容与验证

Windows x64，使用系统 .NET Framework 4.8。已收录 Steam 构建 26266538、26367565 的适配。不同构建的功能是否可用，以各项核验结果为准。
