### 使用

1. 下载EXE到本地文件夹，双击打开。功能默认关闭。
2. 首次使用自动挡时，先正常退出游戏，在工具中选择游戏目录，点击“安装 / 更新组件”。所需组件已经打包；如果缺少微软VC++运行库，工具会从微软官方地址下载并提示授权安装，无需自行寻找安装包。.NET无需另装。
3. 正常启动游戏、进入可控制角色的场景。工具自动检测，也可点“检测 / 重连”，按需开启各项开关。

### 当前功能

- 生存：无限生命、无限体力、无限精纯煞炁（Q绝技资源）。
- 自动挡：**100%防蓝光、100%抗红光、100%入白刃**，分别有独立开关；后台继续可单独选择。
- 小键盘Num1～Num7依次切换上述六项功能和后台继续；没有小键盘可切换“主键盘”。**Ctrl+F8**停止三项自动挡，生存开关保持原状态。
- 最后一个页签提供运行日志与诊断文件导出。

“100%”是功能展示名。已进行的实机验证包括左殇战斗至屋顶剑群之后的一轮无伤反馈及返回主界面；其他敌人、场景和所有攻击并未逐一验证。**100%入白刃在战斗状态下会持续防御，难以移动，请谨慎开启。** QTE由玩家手动处理，工具已移除自动QTE。
